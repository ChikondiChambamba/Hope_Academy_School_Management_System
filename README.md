# School Management Information System

## Overview
A desktop application for managing primary school operations including student records, teacher management, finance tracking, inventory, and attendance.

## Features
- Student enrollment and management
- Teacher records
- Financial management with fee tracking
- Inventory management
- Attendance tracking
- Comprehensive reporting
- Offline database (MySQL)

## Installation
1. Install MySQL Server
2. Install Python 3.8+
3. Install dependencies: `pip install -r requirements.txt`
4. Run database setup: `python setup_database.py`
5. Run application: `python main.py`

## Database Setup
Run the SQL scripts in `database/schema.sql` to create the database structure.
